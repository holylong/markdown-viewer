# Markdown Viewer v0.1.0

Windows x64 桌面 Markdown 编辑器。

## 安装

- `Markdown.Viewer_0.1.0_x64-setup.exe`：常规安装程序，推荐使用。
- `Markdown.Viewer_0.1.0_x64_en-US.msi`：MSI 安装包。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

## 功能

- Markdown 编辑、分屏实时预览和独立预览模式。
- 分屏下编辑区和预览区按滚动进度双向同步，支持预览区鼠标滚轮带动编辑区滚动。
- 每个文档独立保存滚动位置，切换标签后恢复。
- Mermaid 图表、中文内容、浅色与深色主题。
- PDF 和 Word（DOCX）导出，包含图表图片。
- 多文档标签、文件夹浏览和文档右键菜单。
